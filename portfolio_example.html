소개

요구사항을 분석해 설계·구현·연동까지 수행해온 신입 풀스택 개발자 손영선입니다. 유현건설 실무에서는 웹페이지(계측 모니터링)와 어플(현장 조회) 흐름을 각각 구현하며 원시 데이터 수집기 배포, PostgreSQL 적재 파이프라인, 상태 조회 API, 모바일 화면 연동까지 담당했습니다. 스트롱쌀롱은 제가 기획한 목업이 업체에 채택되어 의뢰로 이어진 프로젝트로, 백엔드 전담에서 시작해 프론트까지 맡아 풀스택으로 완성했습니다.

구현 전 로직과 데이터 흐름을 먼저 정리하고, 장애 상황(네트워크 단절/재부팅)에서도 수집이 이어지도록 자동 재시작·재동기화 구조를 적용했습니다.

입사 후에도 코드 리뷰·배포·모니터링 흐름에 빠르게 적응해, API와 화면을 함께 고려한 유지보수 가능한 풀스택 구현으로 팀에 기여하겠습니다.

핵심 역량

Frontend

React Next.js TypeScript Tailwind CSS Axios

React·Next.js·TypeScript 기반으로 실사용 화면에 맞는 컴포넌트 설계, 라우팅, 상태 흐름을 정리한 웹 UI 구현이 가능합니다.

Backend

NestJS Express TypeORM JWT Swagger

NestJS·Express·TypeORM/Prisma로 REST API·인증·권한·검증·예외 처리까지 포함한 백엔드를 구성해 프론트·외부 시스템과 안정적으로 연동한 경험이 있습니다.

Data/Deploy

PostgreSQL MySQL Render Vercel CORS

PostgreSQL/MySQL 모델링과 AWS·Render·Vercel 배포를 실제 서비스 맥락에서 다루며, CORS·환경 변수·연결 오류 등 운영 단계 이슈를 재현·조치한 경험이 있습니다.

프로젝트 소개

유현건설 프로젝트는 웹페이지와 어플을 분리해 실무에 적용한 프로젝트이며, 스트롱쌀롱은 기획·목업 제안 후 확정된 의뢰 프로젝트입니다.

유현건설 웹페이지

현장 계측 데이터를 통합해 실시간 모니터링, 상태 조회, 알림 확인이 가능한 웹 기반 관리 페이지를 구현한 프로젝트입니다.

유현건설 어플

웹과 동일한 데이터 구조를 기준으로 현장 중심 조회, 센서 상태 확인, 핵심 모니터링 기능을 모바일 화면으로 이식한 프로젝트입니다.

스트롱쌀롱

제가 제안한 기획·목업이 채택되어 스트롱쌀롱(1:1 PT 전문)에서 의뢰를 맡긴 웹입니다. 역할 기반 인증, 실시간 일정 알림, 회원 상태 시각화를 통합했습니다. 백엔드 전담으로 시작했으며, 이후 프론트까지 맡아 풀스택으로 완성했습니다.

상세 내용은 아래에서 프로젝트별로 순서대로 정리했습니다.

프로젝트 상세 - 유현건설 웹페이지

프로젝트 소개: 20년 이상 사용하던 레거시 프로그램 환경에서 메모장(txt) 형태의 원시 계측 데이터를 안정적으로 수집·적재하고, 이를 기반으로 웹 대시보드 조회/상태 확인 기능을 제공한 실무 프로젝트입니다.

실무 맥락: 기업 내부에서 오래된 프로그램을 계속 사용 중이었고, 신규 시스템 연동이 어려워 데이터가 메모장 파일로만 누적되던 상황에서 의뢰를 받아 개선했습니다.

포지션: 백엔드 중심 (API 설계/구현, 수집 파이프라인, 데이터 처리)

핵심 구현 범위

  • 수집기 배포: Node.js 기반 수집기를 실행 파일(`node.exe`) 형태로 배포해 현장 환경에서 실행 가능하도록 구성
  • 데이터 적재: 원시 txt 데이터가 추가될 때마다 파싱 후 PostgreSQL로 이관하는 수집/적재 흐름 구현
  • 운영 안정성: 수집기가 백그라운드에서 지속 실행되도록 구성하고, 인터넷 단절/재부팅 이후 자동 재시작 및 데이터 비교 동기화 로직 적용
  • 백엔드 API: NestJS 기반 health/stats/ingest API 구성 및 수집 상태 확인 구조 구현
  • 실시간 알림: WebSocket 통신으로 수위계/지중경사계 값이 임계치를 넘는 경우 알림 이벤트를 전송하도록 구현
  • 연동 규격: DB 스키마와 API 응답 규격을 정리해 프론트 화면에서 대시보드 데이터를 안정적으로 조회하도록 설계

기술 스택

  • Frontend: React, TypeScript
  • Backend: NestJS, TypeScript
  • Data/Agent: PostgreSQL, Node.js 수집기(`node.exe`), ingest API 파이프라인
  • Realtime: WebSocket

라이브러리/도구 활용

  • 파일 입력과 DB 적재 단계를 분리해 수집 오류 원인 추적이 쉽도록 구성했습니다.
  • NestJS 컨트롤러 계층에서 health/stats/ingest API를 분리해 운영 점검 흐름을 명확히 했습니다.
  • 레거시 입력 포맷을 표준화하고 재시작·재수집 동기화 로직을 두어 운영 중 데이터 누락 가능성을 낮췄습니다.

프로젝트 상세 - 유현건설 어플

프로젝트 소개: 유현건설 계측 플랫폼의 핵심 모니터링 기능을 모바일 환경에서 빠르게 조회할 수 있도록 Flutter 기반 어플로 이식한 프로젝트입니다.

구현 맥락: 현장 담당자가 데스크톱 환경이 아니어도 센서 상태, 알람, 대시보드 지표를 확인할 수 있도록 웹 동작 기준을 모바일 UX에 맞춰 재구성했습니다.

포지션: 프론트엔드(Flutter) 중심 + API 연동 설계

핵심 구현 범위

  • 로그인/세션 흐름 구성 및 화면 라우팅 정리
  • 대시보드·센서·알람·현장 등 주요 조회 화면 모바일 최적화
  • 상태 배지/카드 UI를 공통 컴포넌트로 분리해 화면 일관성 확보
  • 목업 데이터 기반 데모 모드와 실제 API 연동 구조를 분리해 전환 비용 최소화
  • 웹 기준 기능 동등성 체크리스트 기반으로 누락 항목 점검

기술 스택

  • Frontend(App): Flutter, Riverpod, go_router
  • Network: Dio
  • Backend/API: NestJS REST API 연동

라이브러리/도구 활용

  • 기능별 폴더 구조를 분리해 인증/대시보드/센서/알람 도메인별 유지보수성을 높였습니다.
  • 공통 테마와 위젯을 적용해 웹과 톤을 맞추면서도 모바일 가독성을 확보했습니다.
  • 데모 모드와 API 모드를 분리해 시연과 실연동 전환을 모두 고려한 구조를 만들었습니다.

프로젝트 상세 - 스트롱쌀롱

프로젝트 소개: 제가 기획·목업으로 제안한 방향이 채택되어 스트롱쌀롱(1:1 PT 전문)의 개발 의뢰로 진행한 관리 시스템으로, 역할 기반 인증·실시간 일정 알림·회원 상태 시각화를 통합했습니다.

의뢰: 스트롱쌀롱 1:1 PT샵

기획: 매장 운영 흐름을 반영한 UI·기능 목업을 제안했고, 업체 검토 후 동일 방향으로 제작 계약이 이어졌습니다.

구현 맥락: 회원·트레이너·결제·일정이 얽힌 매장 운영 흐름을 기준으로 권한 분리와 실시간 알림을 설계했습니다.

진행 형태: 초기에는 백엔드(API·데이터·인증)를 전담했고, 이후 프론트(UI·상태·연동)까지 담당 범위를 넓혀 풀스택으로 마무리했습니다.

포지션: 백엔드 전담 → 프론트 포함 풀스택 완성 (설계·구현·연동)

핵심 구현 범위

  • 회원/트레이너 권한 분리 인증 및 세션 관리 흐름 구현
  • 일정 이벤트 기반 실시간 알림(WebSocket) 연동
  • 헥사곤 지표 시각화를 위한 평가/스냅샷 데이터 모델 구성

기술 스택

  • Frontend: React, TypeScript, Vite, Recharts
  • Backend: NestJS, TypeORM, JWT, Swagger
  • Database/Infra: PostgreSQL, AWS/Render, WebSocket

라이브러리/도구 활용

  • 도메인 모듈 단위(NestJS)로 인증/회원/평가/인사이트를 분리해 구조적 결합도를 낮췄습니다.
  • TypeORM 엔티티와 관계 매핑을 기반으로 회원 상태 지표 계산 흐름을 안정화했습니다.
  • Swagger 문서화를 통해 API 계약을 명시하고 프론트 연동 속도를 높였습니다.

프로젝트 공통 역량

  • 현장·운영자 관점의 요구사항을 기능 단위로 분해하고 우선순위를 정해 구현하는 습관
  • 백엔드 중심으로 데이터·API 계약을 먼저 고정한 뒤 프론트와 안정적으로 맞추는 방식
  • 배포 이후 로그·오류·환경 이슈를 재현하고, 운영 가능한 수준까지 대응해 다듬는 태도
